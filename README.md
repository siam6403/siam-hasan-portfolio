# Mohammad Siam Hasan — Graphic Designer Portfolio

A responsive, static portfolio website built with HTML, CSS and JavaScript. No build tools or paid services are required.

## Preview locally
1. Extract the ZIP.
2. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. Double-click `index.html` to open it in a browser. Internet is only needed for the optional Google Fonts.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account: https://github.com/
2. Create a **public** repository, for example `siam-portfolio`.
3. Upload all files and folders from this ZIP to the repository root. Make sure `index.html` is at the root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for the published site link to appear in Pages.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Before sharing with clients
- The gallery tiles are visual concept panels used as placeholders, not completed client projects. Replace them with real project images when available.
- Verify the biography and service list.
- Add your professional email and WhatsApp link if you want those contact options.
- This is a public website once published. Only upload information you are comfortable making public.
